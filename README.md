# PRESS MATRIX 2026

מאגר מחקרי עולמי לכלי תקשורת מרכזיים בארצות הברית, במזרח התיכון, באירופה ובזירה הדיגיטלית.

## מבנה האתר

האתר עבר למבנה מפוצל וברור:

1. `index.html` — דף ראשי.
2. דפי קטגוריה — למשל `us_tv_channels.html`, `mena_newspapers.html`, `digital_press.html`.
3. תיקיית `media/` — דף עצמאי לכל כלי תקשורת.

## קבצים מרכזיים

- `assets/style.css` — עיצוב מרכזי משותף.
- `assets/media.js` — נתוני כלי התקשורת ומנגנון הצגת הדפים.
- `media/*.html` — דפים עצמאיים לכל גוף תקשורת.

## קטגוריות

- שם כלי התקשורת.
- אזור וסוג.

- מייסד או דמות מרכזית.
- אוריינטציה כללית.

- פירוק שם ואטימולוגיה.

הפרויקט מיועד למחקר, לימוד וארגון מידע היסטורי ותקשורתי. שמות מותגים וסימנים מסחריים שייכים לבעליהם המקוריים.
